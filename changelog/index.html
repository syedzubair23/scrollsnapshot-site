1.5.0LatestOctober 28, 2026

Video frames

Version 1.5 saves the frame a video is showing at the video's own resolution, with a burst of five, subtitles, folders per platform and an optional capture button over videos.

Read the highlights ↗
Added5
  • Video frames

    Choose Video in the popup, or press Alt+Shift+S, to save the frame a video is showing at its own resolution: a 4K video gives a 4K PNG. A copy-protected video is refused with a message, never saved as a black image. Where a site won't hand over a video's pixels, the frame is taken from the screen and the result says so.

    Read the guide ↗
  • Burst of five frames

    With Burst on, one capture takes two frames before the moment, the moment and two after, ⅛ to 1 second apart. The video goes back exactly as it was. Pick a frame on the result page to crop or edit it, or Save all.

    Read the guide ↗
  • Subtitles in frames

    Turn on Include subtitles to put the video's captions into the frame. Where a site draws its own subtitles, the frame is taken from the screen so they show as the site draws them; burst isn't available that way.

    Read the guide ↗
  • Frames by platform

    Frames download into ScrollSnapshot/<Platform>/ and file into a History folder per platform: YouTube, Twitch, TikTok, Douyin, Instagram, Vimeo, or Other videos. History has a Video filter.

    Read the guide ↗
  • A capture button on videos, if you want it

    Off until you turn it on: ScrollSnapshot offers it once after your first video frame. Hover a video and a small camera appears; its menu has Capture & edit, Download frame, Burst and subtitles for that site, and Hide on this site.

    Read the guide ↗
Changed1
  • Alt+Shift+S captures a video frame on new installs

    Slices no longer has a default shortcut. Existing installs keep Alt+Shift+S on Slices until they change it at chrome://extensions/shortcuts.

    Read the guide ↗
1.4.0October 25, 2026

Six languages, and a clearer name

Version 1.4 speaks German, Spanish, French, Japanese and Brazilian Portuguese as well as English, following the language Chrome is set to.

Read the highlights ↗
Added1
  • Six languages

    German, Spanish, French, Japanese and Brazilian Portuguese join English, everywhere: the popup, Settings, the result page and editor, History, the Markdown reader, the on-page pickers and drawing toolbar, error messages and shortcut names. Dates and numbers follow the same language. Any other language shows English.

    Read the guide ↗
Changed1
  • A name that says what it does

    In the Chrome Web Store and on chrome://extensions the extension is now ScrollSnapshot – Full Page Screenshot & Screen Capture, with the same words in each language. Where there is little room, Chrome still shows ScrollSnapshot.

    Read the guide ↗
1.3.0October 22, 2026

Draw before you capture, Markdown everywhere, and your coding agent

Version 1.3 lets you mark up an area before you capture it, adds emoji, turns any page or selection into Markdown, and connects ScrollSnapshot to the coding agent you already use.

Read the highlights ↗
Added8
  • Draw on a region before capturing it

    Once an area is chosen, a toolbar stands beside it: pen, arrow, box, highlight, text, steps and emoji, with colour, options, undo and clear. Pick a mark up to move, restyle or delete it. What you draw is part of the capture; the toolbar never is. Capture & edit opens the result straight in the full editor.

    Read the guide ↗
  • Emoji

    An Emoji tool in the editor and the region toolbar: pick a common one from the panel, or paste or type any other. Move, resize and turn it like any mark.

    Read the guide ↗
  • A note for a region

    Type a short note in the region bar before capturing, and it leads the capture's text.

    Read the guide ↗
  • Text for every capture, plain or Markdown

    Full page and visible captures carry their page's text like a region does, each slice in a ZIP gets its own .txt and .md, and the text panel previews the Markdown and saves .md and .txt files.

    Read the guide ↗
  • Save a whole page as Markdown

    The Markdown button in the popup's header saves any page as a .md file, or opens it as a document with its outline, without taking a screenshot.

    Read the guide ↗
  • Markdown from a text selection

    Turn on the Markdown bar in Settings → Output, and selecting text on any page offers to copy it as Markdown or plain text, or save it. Off by default.

    Read the guide ↗
  • Agent connection

    Claude Code, Codex, Cursor and other MCP clients can read pages as text or Markdown and capture exactly what they need in your own Chrome, in tiles sized to save tokens. Off until you turn it on and pair it; limited to the tab in front of you unless you allow any tab. It can reload a tab, or with any tab open a page, if you allow it — never click, type or run anything.

    Read the guide ↗
  • Send to agent

    Mark up a capture, press Send to agent and say what it should know: the agent gets the image, your note, and your marks as words and coordinates. An agent can also wait for you to send something, or ask you to draw on an area.

    Read the guide ↗
Fixed3
  • No stray navbar in a region

    A region capture no longer includes a pinned navbar from elsewhere on the page.

    Read the guide ↗
  • The article, not the menus

    Text and Markdown leave the navbar, banner and footer out by default; Keep navbar and footer in text, in the popup, puts them back.

    Read the guide ↗
  • Markdown that holds up on real sites

    Code, tables, details, task lists and maths come through properly on documentation, wiki, README, blog and news pages, and text that was missing from inside ordinary page elements is read.

    Read the guide ↗
1.2.0October 16, 2026

A truer palette, and back to the page

Version 1.2 makes the palette show the colours a page is actually designed with, takes you back to the page when you close a capture, and adds ways to send feedback.

Read the highlights ↗
Added2
  • Send feedback and get help

    Settings has Leave a review, Send feedback and Get help at the bottom of its menu. Send feedback opens a short form on this site; the extension itself still sends nothing.

  • A review prompt that waits its turn

    After a few days of use, ScrollSnapshot may ask once, at most twice ever, whether you'd leave a review. It asks only after you copy or download a capture, in a small card in a corner, never while a tool or notice is open, and Don't ask again means it.

Changed3
  • Closing a capture takes you back

    The result tab opens right beside the page you captured, and closing it, or pressing Done, brings that page back to the front.

  • The palette is one icon

    The palette no longer sits over the capture as a card. Click its icon for every colour with its hex and share; click one to copy it, or Copy all for the whole palette, one hex per line.

    Read the guide ↗
  • A palette with the colours that matter

    Small design colours, like a button, a badge or the text, are kept instead of shades of the background. A blend that is not on the page is never listed, and up to eight colours are shown.

    Read the guide ↗
1.1.0October 15, 2026

Folders, a watermark, and a fuller editor

Version 1.1 is about what happens after the capture: keeping it in folders, marking it up, and putting your name on it. It also fixes a run of problems with Turbo, the colour picker, and the popup.

Read the highlights ↗
Added16
  • Folders in History

    Create folders on the History page, select captures (click the box, shift-click a range, or Select all) and move them in from a menu or by dragging them onto a folder. Captures in a folder are never cleaned up automatically, and Clear history can leave them alone. Download a folder, or any selection, as one ZIP.

    Read the guide ↗
  • A menu on every capture

    Every capture and folder has a three-dot menu: open, open the original page, copy the link or the image, download, rename, move, delete.

    Read the guide ↗
  • Your own watermark

    Settings → Watermark adds your text, a logo, or both to what you save, in a corner, along an edge, in the centre, or tiled, with size, opacity, text colour and distance from the edge, and a live preview. It goes on Download, Copy, PDF and slices, and a stamp button on the toolbar switches it off for one capture. Off until you turn it on; the logo stays on this device.

    Read the guide ↗
  • Text options

    The Text tool's size button now opens a panel: size, font (sans, serif, mono, hand), weight, alignment, and italic, underline, background chip and outline switches. Saved style presets remember it. Older text looks the same.

    Read the guide ↗
  • Highlight and Pen options

    Highlight sets strength (25–80%), a block, underline or strikethrough, and a Multiply blend that keeps dark text dark. Pen sets solid, dashed or dotted lines, strength, round or square ends, and smoothing. Both restyle a selected mark and leave earlier marks exactly as they were.

    Read the guide ↗
  • Shapes and line ends

    The Shape tool (B) draws a rectangle, rounded rectangle, ellipse, triangle or diamond. The Line tool (A or L) draws an arrow, a double arrow or a plain line. Shift holds a shape square and a line to 45°.

    Read the guide ↗
  • Edit marks after drawing them

    Shapes come up selected with handles to resize, a grip to rotate (Shift snaps to 15°), and a grip on each end of an arrow. Drag to move, arrow keys to nudge, double-click text to rewrite, Delete, Ctrl+D to duplicate, ] and [ to restack. A new Select tool (V) picks up any mark.

    Read the guide ↗
  • Any colour for marks

    A picker with a colour field, hue strip, hex box, recent colours, and an eyedropper (I) that takes a pixel straight off the capture, plus twelve named colours as small circles at the top of the colour popover.

    Read the guide ↗
  • Redaction brush, eraser, and Blur

    Redact's dropdown now holds Rectangle, Brush and Eraser, the three effects, and a shared brush-size slider. Paint around difficult edges or erase parts of any unapplied redaction, with Undo and Redo for each stroke. Blur sits beside Black out and Pixelate; use Black out for complete coverage.

    Read the guide ↗
  • Straighten in crop

    Straighten by any angle up to 45° either way, with a live preview under a grid. The crop box starts inside the tilted image, so no empty corner is kept.

    Read the guide ↗
  • Zoom, rulers, a grid, and guides

    Zoom on the result page, in the crop box and in the editor: − and + buttons, a readout that toggles fit and actual size, Ctrl/⌘ + wheel, Ctrl/⌘ 0 and 1, and Space-drag to pan. Drag a guide out of a ruler, and drag it back to remove it. A view aid only, never saved into the image.

    Read the guide ↗
  • Cut any capture into slices later

    Slice on the result toolbar: click to cut, drag cuts to move them, use a ruler, cut every N px or into N equal parts, and keep cuts out of lines of text. It cuts down as well as across, and Reassemble puts columns back side by side. Reassemble is now on the toolbar of every slices capture.

    Read the guide ↗
  • PDF in the popup's Format row

    Choose PDF beside PNG, JPEG and WebP and the capture opens on its result page already set to save as a PDF. The image format you had is kept to go back to. Not offered for Slices, or while PDF export is turned off.

    Read the guide ↗
  • Move the toolbar to the left or right

    Every result-page bar stands upright against either side, or stays along the bottom, from the toolbar's own position button or Settings → Output. Zoom is part of each bar, and the capture keeps clear of it.

    Read the guide ↗
  • Turbo's viewport width for Slices

    Turbo can now lay a page out at a mobile or tablet width for Slices, as it already did for Full page.

    Read the guide ↗
  • Reset settings

    “Reset this page” on each settings page and “Reset all settings”, both of which ask first. Consent, seen hints, saved presets and recent colours are kept.

    Read the guide ↗
Changed6
  • Crop is a crop box

    It opens around the whole capture: drag edges and corners, drag inside to move, type an exact width and height, hold a ratio, nudge with the arrow keys, and rotate or flip the capture.

    Read the guide ↗
  • Toolbars fit any window

    When a toolbar is longer than the window, its middle scrolls and fades at the edge with more. Download, Apply, Cancel, Undo and Redo stay pinned. Format and size share one “PNG · 100%” button, and Copy, Crop, Edit and Slice are icons with tooltips.

    Read the guide ↗
  • Turbo's width dropdown is on by default

    Turning Turbo on now offers mobile and tablet widths straight away. Standard mode cannot offer it: it photographs the real window.

    Read the guide ↗
  • A calmer popup

    The popup scrolls only its options; the modes stay put above them, and Format and Turbo stay put above Capture. Each mode's icon opens a card with its name, shortcut and what it makes, and the Capture button names the mode.

  • A sharper colour picker

    An 11 × 11 loupe that moves a pixel at a time with the arrow keys, copies HEX, RGB or HSL (Tab), and refreshes after the page scrolls. The popup's button is an eyedropper; the target icon now means only “click an element on the page”.

    Read the guide ↗
  • Smaller changes

    “Pick elements to leave out” is in the popup by default. The editor always shows the colour, including while Redact or Select is chosen. Resetting settings asks first, in a dialog that says what goes back and what is kept. Toolbars, menus and tools ease in; reduced-motion settings still turn it all off.

Fixed10
  • Turbo no longer catches a sliding navbar

    Sites that hide a navbar on scroll down and slide it back on scroll up were captured with the bar still moving. Turbo now waits for fixed and sticky elements to stop moving before it renders, and starts from the top of the page so a fixed header cannot shift.

    Read the guide ↗
  • Turbo works in a zoomed tab

    With browser zoom other than 100%, Turbo used to capture a magnified, shorter stretch of the page, and a chosen width came out narrower than asked (375 became 300). It now allows for the tab's zoom.

    Read the guide ↗
  • Turbo no longer repeats the page partway down

    Tall pages crossed Chromium's single-render limit, past which the image starts over from the top. Turbo now renders at the real ratio and splits tall pages into bands. Pages taller than one image can hold are scaled to fit, with the same notice as the standard engine.

    Read the guide ↗
  • Slices no longer repeat a cookie banner

    Pinned elements such as a cookie banner or sticky header are kept in the first slice only, as Full page does.

    Read the guide ↗
  • The colour picker reads the right pixel

    It scaled by the viewport without its scrollbar, so samples landed up to about 15 px off: right on flat colour, wrong inside images.

    Read the guide ↗
  • A page can no longer read the colour picker's screenshot

    The loupe sat where page scripts could reach it, so a script could walk it across the screenshot and read pixels it cannot otherwise see, such as a cross-origin frame's. It is now out of the page's reach.

    Read the guide ↗
  • Copy can be pressed again

    The “Copied” mark on an automatic copy never cleared. It now fades after a moment, and the button is always Copy.

  • Tooltips tell the truth

    The popup's mode tooltips name the shortcut Chrome actually assigned, and side toolbars show their tooltips beside the bar instead of clipped by it.

  • The extension icon shows again

    In the toolbar, the extensions menu, and on ScrollSnapshot's own pages.

  • No error after an extension reload

    A reloaded extension no longer throws “Extension context invalidated” on the colour picker's scroll; the picker ends quietly.

    Read the guide ↗
1.0.0September 19, 2026

The first release

Full-page, region, slice and batch screenshots that stay on your device, with an editor, local history, and exports in four formats.

Added8
  • Four capture modes and batch

    This screen, Full page, Slices and Region, plus a Batch queue for the tabs in a window or up to 50 pasted addresses.

    Read the guide ↗
  • Standard and Turbo engines

    A scroll-and-stitch engine that works on every page, and an optional one-shot Turbo engine with a chosen viewport width.

    Read the guide ↗
  • Precise regions

    Draw, move and resize a region, trace a freeform shape, type page coordinates, or capture an element by CSS selector or XPath.

    Read the guide ↗
  • Page-aware capture

    Capture a panel that scrolls on its own, start a full page from where you are, set a delay before capture, and leave out elements such as a cookie banner.

    Read the guide ↗
  • An editor

    Crop, redact, annotate, number steps, and keep your annotation style in presets.

    Read the guide ↗
  • Text and colours from the page

    Read the real page text under a region without OCR, pick a pixel's colour, and copy colours from an extracted palette.

    Read the guide ↗
  • Four formats, local history

    Save as PNG, JPEG, WebP or PDF at the scale you choose. An optional on-device history lets you search, filter, favourite and reopen captures, and reassemble a Slices ZIP.

    Read the guide ↗
  • Settings you can tune

    Capture, Batch, Features, Output, Slices and Shortcuts, with a light, dark or system appearance.

    Read the guide ↗
