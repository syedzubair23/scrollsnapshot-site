Start from where you are

When the useful section begins halfway down a page, Start from where you are begins the full-page capture at the current scroll position instead of going back to the top.

IN THIS GUIDEA practical momentUse the current positionAll guides ↗
01

A practical moment

Use it after navigating to a chapter, a result section, or a long thread whose opening is irrelevant. The result still follows the page downward from the position you chose.

02

Use the current position

  1. Scroll to the first content you want included.
  2. Choose Full page and turn on Start from where you are.
  3. Capture, then check the first row of the result before saving.
KEEP IN MIND

Leave this off when you need an image that begins at the document's top.
