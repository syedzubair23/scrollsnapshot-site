Let your coding agent see the page

A coding agent works from your code; it cannot see the page that code produces, especially one behind your login. The agent connection lets it read a page as text, take exactly the screenshot it needs, and look at what you mark up, through ScrollSnapshot in your own Chrome.

01

Set it up once

  1. Open ScrollSnapshot → Settings → Agent connection and turn on Allow an agent to connect.
  2. Choose your agent. Copy the line shown for it and your operating system, and run it in a terminal (or paste the settings snippet into your client). It needs Node.js 22 or newer; nothing else to download.
  3. Run npx -y scrollsnapshot-mcp pair, copy the secret it prints, paste it into Settings and press Pair.
  4. Start your agent. Within 30 seconds the toolbar icon shows AI: it is connected.
  • If it does not connect, run npx -y scrollsnapshot-mcp doctor. It checks each link and prints the line that fixes what is wrong.
02

What an agent can do

Read a page: its outline of headings, landmarks, forms and tables, each with a selector, and its text, plain or as Markdown. Capture it: the screen, the whole page, one element by selector, or an area, returned in tiles sized to keep the agent's token use down, with the full-resolution file saved on disk. Read your capture history, and pick up screenshots you send it.

It can also ask you to choose an area. The region picker opens on your screen, and the note and drawings you add reach the agent as words and coordinates, not only pixels.

03

Which tabs, and what it may change

By default an agent can use only the tab in front of you. Choose Any tab to let it list and capture every open tab.

Turn on Let agents open and reload tabs and the agent can reload a tab to see a change it just made. With Any tab, it can also open a web page in a new tab, such as your local dev server. It can never click, type or run anything on a page.

04

Where your data goes

ScrollSnapshot hands what an agent asks for only to the agent server on your own computer, after both sides prove they hold the pairing secret. Your agent may then send it to its AI provider, as it does with your code and everything else you show it. The server keeps the captures it receives in a private folder in your home directory and deletes them after seven days.

KEEP IN MIND

The agent connection is off until you turn it on, and the pairing secret never leaves this device. The privacy policy covers it in detail.
