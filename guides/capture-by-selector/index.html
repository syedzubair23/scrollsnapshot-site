Name the element, capture its box

When the target is a specific component, naming it can be steadier than measuring pixels. Region's Selector choice resolves a CSS selector or XPath expression and captures the first matching element's box.

IN THIS GUIDETwo ways to chooseKeep the target unambiguousAll guides ↗
01

Two ways to choose

Type a selector in the popup, or use the target control to click the element on the page. The click picker highlights the target; the up and down arrows move between it and its parent. A clicked element confirms the capture in one step.

02

Keep the target unambiguous

  1. Choose Region, then Selector.
  2. Enter a specific CSS selector or XPath expression, or pick the element directly.
  3. Inspect the result to confirm the first match was the one you intended.
KEEP IN MIND

Invalid selectors, missing matches, and zero-size elements are refused with an explanation. If the page reflows, an element target is often more reliable than typed coordinates.
