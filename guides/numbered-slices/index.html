Keep a long page at full resolution

Slices is the deliberate answer to a page too tall for a single bitmap. Instead of silently shrinking it, ScrollSnapshot saves full-resolution pieces in a ZIP and records where each piece belongs.

IN THIS GUIDEChoose the cutWhat is in the archiveWork with the resultAll guides ↗
01

Choose the cut

You can take one piece per screen height, specify a pixel height, or ask for an exact number of parts. Optional overlap repeats a little content at each boundary, useful when a line of text would otherwise sit on a seam.

02

What is in the archive

The images are numbered in page order and padded so they sort correctly in a file manager. A manifest records their page coordinates. The archive remains useful even after it leaves the extension because the positions are explicit.

03

Work with the result

  1. Choose Slices, set the height or count, and add overlap if the page has dense text.
  2. Capture and inspect the slice previews in the result page.
  3. Download the ZIP, or use Reassemble to make a separate single-image capture for editing.
KEEP IN MIND

Reassembling an extremely tall archive into one image can still require downscaling. The original ZIP keeps the full-resolution pieces.
