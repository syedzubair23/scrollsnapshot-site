Choose the file after seeing the image

A screenshot's best format depends on what it contains and where it is going. ScrollSnapshot lets you choose after capture, without photographing the page again.

IN THIS GUIDEThree image choicesSize and destinationA practical checkAll guides ↗
01

Three image choices

PNG is lossless and keeps transparency. JPEG is smaller for photographic pages but has no transparency. WebP can be compact while preserving transparency. The result page re-encodes the current image when you switch formats.

02

Size and destination

The Scale control can export at 100, 75, 50, or 25 percent without shrinking the stored source. Download keeps the chosen file format. Copy sends PNG because the browser clipboard accepts PNG image data for this workflow.

03

A practical check

  1. Inspect the finished capture and choose a format.
  2. Choose a smaller output scale only if the recipient does not need full detail.
  3. Download or copy, then check the result at its intended viewing size.
KEEP IN MIND

For a document that needs paper pages, use PDF export instead of stretching an image into a print layout later.
