Read the words in a capture

A screenshot is pixels, but a web page also has text. Every capture now carries the text of what it shows, read from the page itself, so you can copy a quote, a table or a code block without retyping it or guessing at it with OCR.

IN THIS GUIDEOpen it from the iconThe browser has the sourceSlices carry theirs tooAll guides ↗
01

Open it from the icon

On the result page, the text icon under Done opens the page text: the words under a region, or the whole page for a full page or visible capture. Choose Plain or Markdown, see the Markdown as formatted text in Preview, copy it in one click, or save it as a .md or .txt file. A note typed in the region picker comes first.

02

The browser has the source

The reader preserves document order and structure, and reads the actual characters, including non-Latin scripts. Markdown keeps headings, emphasis, links, lists, code blocks, images, quotes and tables. The navbar, the banner and the footer are left out so you get the article; Keep navbar and footer in text, in the popup, puts them back.

03

Slices carry theirs too

A Slices ZIP has a .txt and a .md next to each picture, holding the words of that slice, and the whole page's text alongside.

KEEP IN MIND

Words baked into an image or a cross-origin frame are not page text the extension can read. A redaction withholds extracted text so it cannot expose what the image covers.
