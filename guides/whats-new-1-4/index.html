What's new in ScrollSnapshot 1.4

Version 1.4 speaks your language. German, Spanish, French, Japanese and Brazilian Portuguese join English, everywhere in the extension, following the language Chrome is set to.

IN THIS GUIDESix languagesA clearer name in the Chrome Web StoreGetting the updateAll guides ↗
01

Six languages

The popup, Settings, the result page and editor, History, the Markdown reader, the on-page pickers and drawing toolbar, error messages and shortcut names all follow Chrome's language. Dates and numbers do too. Any other language shows English.

02

A clearer name in the Chrome Web Store

The extension is now listed as ScrollSnapshot – Full Page Screenshot & Screen Capture, with the same words in each language, so it is easier to find. Where there is little room, Chrome still shows just ScrollSnapshot. Nothing else about it changes.

03

Getting the update

  1. Chrome updates extensions on its own, usually within a day or two of a release.
  2. To check now, open chrome://extensions, turn on Developer mode, and choose Update.
  3. Look for version 1.4.0 on ScrollSnapshot's card.
KEEP IN MIND

The changelog lists every change in this release. To see ScrollSnapshot in another language, change Chrome's language: the language guide shows how.
