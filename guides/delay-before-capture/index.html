Give the page a few seconds

Some UI disappears as soon as you move to the extension popup. A capture delay gives you a short countdown to return to the page and open the state you want to show.

IN THIS GUIDEThe countdown comes firstSet up the momentAll guides ↗
01

The countdown comes first

ScrollSnapshot waits before preparing or moving the page, so the menu or hover state you create during the countdown is not disturbed early. The worker owns the timer even after the popup closes.

02

Set up the moment

  1. Enable Delay before capture on the Features page if it is hidden.
  2. Choose the delay in the popup and press Capture.
  3. Return to the page, open the menu or hover state, and let the countdown finish.
KEEP IN MIND

Cancel during the countdown stops before the page is touched.
