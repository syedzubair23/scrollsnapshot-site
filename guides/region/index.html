Capture only what you mean

A region capture starts with a boundary you control. Draw a rectangle on the page, trace a freeform shape, or enter exact page coordinates when the target is below the fold.

IN THIS GUIDEThe selection is still yours after the dragChoose the shapeA reliable sequenceAll guides ↗
01

The selection is still yours after the drag

A drawn rectangle can be moved and resized before confirmation. Enter confirms; Escape cancels without keeping a capture. The overlay measures against the visible viewport, while typed coordinates are measured from the document's top-left corner.

02

Choose the shape

A rectangle keeps its full box. A freeform lasso makes the area outside the path transparent, so the result uses a format that can preserve transparency. A region taller than one screen can be stitched like a full-page capture.

03

A reliable sequence

  1. Choose Region and select Draw or Coordinates.
  2. Set the boundary, then adjust it if needed.
  3. Confirm the selection and inspect the captured pixels before exporting.
KEEP IN MIND

If the target is a stable page element, Capture by selector can be more repeatable than typed pixel coordinates.
