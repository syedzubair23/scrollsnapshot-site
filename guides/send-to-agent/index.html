Show your agent what is wrong

Some problems are faster to point at than to describe. Mark the broken part, number what should happen, add a sentence, and the agent receives the picture, your note, and a readable list of your marks.

IN THIS GUIDESend a captureWhen the agent asksWhether or not an agent is listeningAll guides ↗
01

Send a capture

  1. Capture the page and mark it up: a box around the problem, numbered steps, an arrow.
  2. Press Send to agent on the result page. It appears while the agent connection is on.
  3. Write what the agent should know, and press Send.
  • Numbered steps plus a note are the clearest way to say “1 is broken, 2 should look like 3”: the agent receives each step's number and position.
02

When the agent asks

An agent can ask you to show it something and wait. Send to agent as usual, and its wait ends with your screenshot. It can also ask you to choose an area: the region picker opens, you draw on the area and add a note, and both reach the agent with the capture.

03

Whether or not an agent is listening

What you send waits in a small inbox on this device, the newest 20, until an agent picks it up. Anything you redacted is described only by where it is; what it hid never travels.

KEEP IN MIND

Send to agent appears only while the agent connection is on in Settings. What you send goes to the agent server on your own computer, and from there wherever your agent sends what you show it.
