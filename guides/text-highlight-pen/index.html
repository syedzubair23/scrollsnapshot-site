Style the text, highlight, and pen

The Text, Highlight, and Pen tools each have a panel of options. The options set the next mark you draw, restyle a mark you have selected, and are remembered by saved style presets.

IN THIS GUIDETextHighlightPenSet once, reuse oftenAll guides ↗
01

Text

Choose the Text tool and press the size button that appears beside the colour. It opens a panel with:

  1. Size: Small, Medium, or Large.
  2. Font: Sans, Serif, Mono, or Hand.
  3. Weight: Regular, Semibold, or Bold.
  4. Align: Left, Centre, or Right.
  5. Four switches: Italic, Underline, Background, and Outline.
  • Background puts a chip behind the words, which keeps small text readable over a busy page.
  • Outline does the same job on a photograph or a gradient, where a flat chip would look heavy.
  • Mono is a good fit for labelling code, file names, and numbers.
02

Highlight

Highlight's dropdown sets its strength from 25 to 80 percent, and whether the mark is a block, an underline, or a strikethrough. A block is the familiar marker. An underline is quieter, and a strikethrough marks something as removed or wrong.

A Multiply blend keeps dark text dark underneath a bright highlight, the way a real marker lets the ink show through, instead of washing it out.

03

Pen

Pen's dropdown sets a solid, dashed, or dotted line, its strength, round or square ends, and smoothing. A dashed pen is a natural fit for a region that is optional or a path that is only suggested. More smoothing steadies a shaky hand-drawn line.

04

Set once, reuse often

All three panels restyle a selected mark as well as setting the next one, and the choices are saved in style presets. Older text, highlights, and strokes look exactly as they did: the options change only what you set from now on.

  1. Choose a tool and set its options in the panel.
  2. Draw the mark, or pick an existing one up with the Select tool to restyle it.
  3. Save the look as a style preset if you will use it again.
KEEP IN MIND

Pick an option before drawing to set the next mark, or select a mark first to change that one. The controls work in both cases.
