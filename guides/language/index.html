Use ScrollSnapshot in your language

ScrollSnapshot speaks English, Deutsch, Español, Français, 日本語 and Português (Brasil). There is no language setting to find: it reads whatever language Chrome itself is using.

IN THIS GUIDEWhat changesChange the language on Windows, Linux or ChromeOSChange the language on a MacAny other languageAll guides ↗
01

What changes

Everything ScrollSnapshot shows you: the popup, Settings, the result page and editor, History, the Markdown reader, the pickers and drawing toolbar on the page, error messages and the names of its keyboard shortcuts. Dates and numbers are written the way your language writes them. Its name and summary in the Chrome Web Store and on chrome://extensions follow too.

Your captures and the text taken from a page stay exactly as the page wrote them.

02

Change the language on Windows, Linux or ChromeOS

  1. Open Chrome's settings and choose Languages, or go to chrome://settings/languages.
  2. Add the language if it is not listed, then open its ⋮ menu and choose Display Google Chrome in this language.
  3. Press Relaunch. ScrollSnapshot opens in the new language.
03

Change the language on a Mac

On macOS, Chrome uses the language of the system. Change it in System Settings → General → Language & Region, either for the whole Mac or for Google Chrome alone under Applications, then quit and reopen Chrome.

04

Any other language

Chrome set to a language ScrollSnapshot does not have shows it in English. Spanish covers every Spanish Chrome offers. Portuguese is written for Brazil, so Chrome set to Portuguese (Portugal) shows English.

KEEP IN MIND

The translations are new in 1.4. If a word reads oddly in your language, say where on the feedback page, and it will be put right in the next update. These guides are in English.
