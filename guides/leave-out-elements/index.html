Leave the obstruction out

A cookie banner or chat bubble can cover the content you came to capture. Leave out elements lets you point to those page elements before the screenshot is taken.

IN THIS GUIDEWhat changesUse it before selecting a regionAll guides ↗
01

What changes

The chosen element is temporarily removed from the page layout, so content beneath it can close the gap. ScrollSnapshot restores it when the capture finishes, fails, or is cancelled. Text extraction also follows the page without the omitted element.

02

Use it before selecting a region

  1. Enable Leave out elements on the Features page if needed.
  2. Start the capture and click the obstructing element in the picker.
  3. Complete the capture and inspect the content that was revealed.
KEEP IN MIND

Use this for an obstruction, not for editing private pixels. Redact a finished capture when information must be covered in the saved file.
